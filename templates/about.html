DenseNet201 Backbone
201 Layers

DenseNet (Densely Connected Convolutional Networks) overcomes the vanishing-gradient problem by connecting each layer to every other layer within a dense block. Instead of summing activations like ResNet, DenseNet concatenates feature maps, encouraging feature reuse and reducing parameter redundancy.

• Total Parameters: 18,568,259
• Conv Blocks: conv1, conv2_block, ..., conv5_block
• Final Feature Layer: conv5_block32_concat
Explainable Grad-CAM
conv5 Target

Gradient-weighted Class Activation Mapping computes the gradient of the predicted class score with respect to the feature activation map of the final convolutional layer. The resulting coarse localization heatmap identifies discriminatory regions in the oral lesion without altering model weights.

• Target Layer: conv5_block32_concat
• Color Map: OpenCV JET Palette
• Superimposition: 60% Image + 40% Heatmap
Certainty Safeguard & Abstention
≥ 60% / ≥ 10%

To protect clinical validity and prevent overconfident hallucinations on atypical photographic artifacts, the inference pipeline enforces mathematical thresholds: predictions require at least 60% confidence and a 10% margin separation from the runner-up class.

• High Confidence: ≥ 80.0%
• Moderate Confidence: 60.0% – 79.9%
• Low / Inconclusive: < 60.0% or Margin < 10.0%
Verified Preprocessing Standard
Pillow RGB

Incoming image bytes are loaded via Pillow to confirm valid image headers, stripped of alpha channels, converted to 3-channel RGB, resized through bilinear interpolation to 224×224, and scaled into 32-bit floating point representations strictly bound to [0.0, 1.0].

• Input Shape: (None, 224, 224, 3)
• Data Type: float32 normalized
• Checksum Verification: SHA-256 Validated
